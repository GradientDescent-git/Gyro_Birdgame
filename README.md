# VisionBird

## Real-Time Computer Vision Gesture-Controlled Physics Game

VisionBird is a real-time computer vision interaction project that enables
touchless control of a physics-based slingshot game using hand tracking
and gesture recognition.

## Core Technologies

- Python
- OpenCV
- MediaPipe
- Pygame
- Pymunk

## Architecture

Webcam → Hand Tracking → Gesture Detection → Control State Machine → Game Input → Physics Engine

## Status

Active development.
